# Agenda Cultural CG

Aplicação front-end de demonstração para a agenda cultural de Campo Grande/MS.

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router DOM
- Lucide React

## Como executar

1. Instale as dependências:
   npm install
2. Inicie o projeto:
   npm run dev
3. Acesse no navegador:
   http://localhost:5173
